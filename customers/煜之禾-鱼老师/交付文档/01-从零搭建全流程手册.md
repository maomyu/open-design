# 爆创 · 从零搭建全流程手册

> 适用对象：拿到一台全新 macOS 电脑、不懂代码的你（煜之禾·鱼老师）。
> 目标：只照着这一份文字，就能把整套「自媒体爆款监控系统」从 0 装起来、跑起来、用起来。
> 版本：定制版 WorkBuild（品牌名「爆创」），个人自媒体全功能授权，授权有效期至 2027-12-31。
> 阅读方式：每步都写清「做什么 / 在哪做 / 成功标志 / 失败怎么办」。看不懂的命令，直接整行复制给交付方即可。

---

## 第 0 章　这套系统到底能帮你做什么

一句话：**你只管出镜和拍，选题和文案让系统替你干。**

它自动做这条流水线：**① 六平台采集 → ② 爆款打分 → ③ 爆点拆解 → ④ 素材召回 → ⑤ 口播脚本 → ⑥ 封面生成**，而且**每一步结果都自动存进你自己名下的飞书表格**，手机随时看、审、复盘。

- **六平台**：抖音、小红书、B站、快手、视频号、公众号。采集用专业数据源 TikHub，**不需要登录任何账号**，直接拿到带点赞/评论/粉丝数的真实爆款数据。
- **打分**：按爆款标准（绝对热度、低粉高表现、账号异常、关键词头部等规则先筛，再用「流量爆款分 + 精准意向分」双通道 0–100 打分，分 S/A/B/C），并给出**评分理由**。
- **拆解 + 脚本**：把爆款视频口播（自动语音转写 ASR）或图文全文取出，AI 拆出「前 3 秒钩子 / 核心矛盾 / 用户痛点 / 内容结构」，再结合你的**个人知识库**和**口播风格**，写出像你本人说话的原创口播脚本（多平台、多时长、多版本）。
- **封面**：给一张参考封面，生成同类视觉语言新封面（抖音竖版 + B站横版），中文标题用程序叠字**100% 不错字**；只改标题时不重新出图，秒出新版。
- **发布**：一律「**自动存草稿箱，最后由你人工点发布**」——对外动作永远你亲手点，系统绝不自动发。

整套装在一个 Mac 应用「爆创」里。核心采集/打分/脚本这条「引擎管道」即使把桌面程序全关掉，也能靠定时任务独立运行。

## 第 1 章　安装应用

### 1.1 你会拿到什么
一个 **`.dmg` 安装包**（如 `WorkBuild-xxxx.dmg`），交付方通过网盘/U盘/AirDrop 给你。

### 1.2 安装步骤
1. 双击 `.dmg`，弹出窗口里有**爆创图标**和「应用程序」文件夹快捷方式。
2. 把**爆创图标拖到「应用程序」**，松手等复制完成。
3. 关窗口，推出白色磁盘图标（点旁边⏏）。
4. 「启动台」或「应用程序」里找到**爆创**双击启动。

**成功标志**：出现主界面（左侧导航：文章/短视频/笔记/知识库/账号/集成）。

**失败怎么办**：
- 提示「爆创已损坏 / 无法验证开发者」= macOS 安全拦截(Gatekeeper),不是坏了。两种解法：
  - **右键打开**：应用程序里找到爆创,**按住 Control 点它 → 打开 → 再点一次打开**。第一次这样以后能正常双击。
  - 仍不行,打开「终端」粘贴回车：`xattr -dr com.apple.quarantine /Applications/WorkBuild.app` 再双击。
  - 若交付方给的是**已签名公证版**,完全没这提示,直接双击。
- 提示「已存在」= 装过旧版,先把旧的拖废纸篓再拖新的。

### 1.3 首次启动会自动「装引擎」（只发生一次,重要）
采集/打分/脚本由内置 Python 引擎驱动,**第一次启动会在后台自动装好它**(解压运行时/ffmpeg/飞书命令行 lark-cli,建环境+离线装依赖)。

**做什么**：什么都不用做,**耐心等 1–5 分钟**。
**成功标志**：之后去账号页点「连接飞书」或创作台点采集,**不再提示「引擎准备中/失败」**,能正常出结果。之后每次秒开。
**失败怎么办**：首启马上操作可能提示还在准备,等一两分钟再试;长时间「准备失败」→ 完全退出重开(自动重试),仍不行截图给交付方(多为安装包缺件或磁盘空间不足)。

## 第 2 章　准备各项 API Key（钥匙）

### 2.1 先理解：钥匙放哪、归谁
系统要调几家外部服务(采集/AI文本/AI图像/语音)。每家要一把 API Key。
- **Key 是你自己的**：用你的账号申请,费用走你账户,**只存这台 Mac,绝不外发、不上云**。
- **引擎读钥匙的地方**：这 4 类 Key 写在引擎配置文件 **`.env`** 里(应用数据目录内,首启自动生成,你不用自己找)。
- **通常你不用手动填**：交付时交付方会**把你提供的 Key 预填进你这份包的 `.env`**,出厂即用。你要做的是照下面**申请出来交给交付方**(账号钥匙都是你的)。

带 ★ 的是必需,其余增强/兜底。

### 2.2 ★ TikHub —— 六平台爆款采集(最关键)
- **是什么**：第三方数据接口,不登录不怕反爬拿六平台爆款数据。没它采不到选题。
- **申请**：https://api.tikhub.io/ 注册 → 控制台生成 API Key + 充额度。
- **填哪**：引擎 `.env` 的 `TIKHUB_API_KEY`(交付方填);应用内「集成页 → 连接器 → 第三方 API Keys」也可填一份给创作台下载单条视频用。

### 2.3 ★ DeepSeek —— AI 文本(拆解/脚本/标题)
- **申请**：https://platform.deepseek.com/ 注册 → API Keys 新建 + 充额度。
- **填哪**：`.env` 的 `DEEPSEEK_API_KEY`。模型已配好(低/中层 deepseek-chat,高层 deepseek-reasoner)。

### 2.4 ★ 火山方舟 ARK —— AI 图像 + 参考封面视觉解析
- **申请**：https://console.volcengine.com/ark 实名登录 → 创建 API Key → **在「开通管理」开通:一个生图模型(doubao-seedream)+一个视觉理解模型(doubao-vision)**。
- **填哪**：`.env` 的 `ARK_API_KEY`;模型名已配(`IMAGE_MODEL`/`VISION_MODEL`)。
- **提醒**：没开通视觉模型时,封面「参考图解析」自动降级为「主色提取+图生图」,封面照出(验收证明效果不受影响);开通任一 doubao 视觉模型后**自动升级**,无需改配置。

### 2.5 ★ 火山语音 ASR —— 口播转写
- **申请**：火山引擎「语音技术」控制台开通「录音文件识别」→ 拿访问凭证。
- **填哪**：`.env` 的 `ASR_PROVIDER=volc`/`ASR_API_KEY`/`ASR_BASE`。
- **说明**：没配时脚本只按标题写(信息少);配好后几十秒短视频能转几百字口播,脚本质量明显更好。

### 2.6 大家啦 dajiala —— 公众号阅读兜底(可选)
- **申请**：https://www.dajiala.com/ 注册拿 Key → 填 `.env` 的 `DAJIALA_KEY`。不配也能跑,公众号那路数据弱些。

### 2.7 飞书 —— 不用你手动申请 Key!
飞书**不需要去开放平台申请应用、不用复制任何 App ID/Secret**。爆创内置飞书命令行工具,用**扫码授权**在你自己飞书里自动建免费自建应用并授权。你只要**有飞书账号**(建议能创建自建应用的团队/企业飞书)。三步操作见第 3 章,系统自动把新建表地址写回配置,全程不碰 Key。

### 2.8 以后自己换 Key
引擎以 `.env` 为准,换 Key 两种方式:①推荐:新 Key 发交付方帮改;②进阶:编辑 `.env` 找到对应键名(如 `TIKHUB_API_KEY=`)替换值,保存,**完全退出重开**生效(改错会致功能失效,改前备份)。

## 第 3 章　连接飞书 + 一键建数据中心

界面在「账号」页最上方**飞书数据中心**卡片,三步向导。

### 3.1 打开位置
左侧导航「**账号**」→ 页面最上「📊 数据源 · 结果存储 → 飞书数据中心」卡片,有带圈 ①②③ 三步。

### 3.2 第①步：连接你自己的飞书
点「**连接飞书**」→ 应用弹出「👉 点此打开飞书官方页面」→ 用**你自己的飞书**扫码/登录 → 按提示「创建应用并授权」。
**关键**：向导**全程自动推进**——建好应用自动跳「本人登录」,你只管在飞书点「授权」,**授权成功界面自动变绿,不需要回来点任何按钮**(旁边「刷新一下」通常用不到)。
**成功标志**：第①步变绿「✓ 已连接你的飞书」。
**失败怎么办**：红字「未检测到 lark-cli」→ 引擎没装好或需重启,**完全退出重开**等引擎就绪再连;半天不变绿→确认你在飞书**真的点了授权**。

### 3.3 第②步：创建数据中心(10 张表)
①变绿后点「**在我的飞书创建数据中心(10 表)**」→ 系统在**你自己飞书名下**新建多维表格,自动建 10 表+字段+默认配置,约 1 分钟。
**成功标志**：提示「已创建 ✓」,下方链接框自动填入你的飞书表格地址。
**失败怎么办**：确认①是绿的、授权没过期,再点一次;反复失败截图给交付方。

### 3.4 第③步：打开查看
点「**打开飞书数据中心**」用内置浏览器打开(首次登录你的飞书)。**成功标志**:能看到这 10 张表:

| 编号 | 表名 | 作用 |
|---|---|---|
| ① | 爆款内容原始库 | 各平台原始抓取+多期快照+去重 |
| ② | 今日爆款选题池 | 当日爆款选题、评分、榜单、承接建议 |
| ③ | 爆点拆解库 | AI 拆的钩子/痛点/结构 |
| ④ | 成品内容审核库 | 脚本+封面+审核状态(你在这审稿) |
| ⑤ | 发布复盘库 | 发布数据回流+成本+错误摘要 |
| ⑥ | 监控配置库 | 你的关键词/竞品(第4章配这) |
| ⑦ | 我的素材库 | 口播素材/封面参考(供AI召回) |
| ⑧ | 风格画像库 | 你的口播风格(控脚本语气) |
| ⑨ | 系统配置表 | 阈值/频率/TopK/默认模型(可在飞书直接改) |
| ⑩ | Prompt与模型策略库 | 预留表(Prompt当前在代码内,⑨里已能改默认模型) |

> 数据全在**你自己飞书名下**,和开发方账号无关,手机随时看审复盘。

## 第 4 章　配置监控(告诉系统盯什么)

系统定时采集读的就是「监控配置库⑥」里勾了启用的项。两种方式任选。

### 4.1 界面配(推荐)
账号页 →「**定时监控**」卡片:
- **加关键词**:填方向词(脱单/相亲/男性成长)、选平台、可设最低阈值,**勾「是否启用」**。
- **加竞品账号**:类型选「竞品账号」,填主页链接或名称,选时间窗(1d/7d/30d/180d)。
- 建数据中心时预置一条示例行「男性情感」(默认未启用),照它改成你的方向再勾启用。
**成功标志**:列表出现你加的项且「启用」。**失败**:加不进多半飞书连接断了,回第3章确认①绿。

### 4.2 全局参数卡片
同页「**全局参数**」对应飞书「系统配置表⑨」:各阈值/检测频率/TopK/默认模型都能看和改,改完下次跑生效。命令等价 `od monitor config`。

### 4.3 命令行配(等价,适合批量)
```bash
od monitor add --keyword "男性情感" --platforms 小红书,抖音   # 加关键词监控
od monitor list                                              # 看所有监控项
od monitor rm <recordId>                                     # 删某项
```

## 第 5 章　日常使用(创作动线)

最短路径:**配监控 → 采集出选题 → 挑一条仿写脚本 → 一键存草稿 → 标记完成 → 复盘**。

### 5.1 三个创作台 + 知识库
左侧导航即入口:
- **文章**:公众号/知乎/微博文章形态(你的授权含公众号)。
- **短视频**:抖音/快手/视频号/B站/小红书。真抓爆款选题 → 提取口播 → 按知识库/风格仿写 → 下载原视频 → 一键存草稿。
- **笔记**:小红书图文笔记。
- **知识库**:公司级资产,一处维护三台共用。放你的**账号人设/核心观点/口播风格/个人故事/金句/目标人群**,填越好 AI 写越像你。

### 5.2 一条完整动线
1. **出选题**:短视频台点「真抓爆款」(或 `od baokuan collect`),候选和评分写飞书选题池②。
2. **挑一条 → 仿写**:选中选题,提取口播,AI 结合知识库+风格画像生成脚本。
3. **不满意就调**:去飞书「风格画像库⑧」把某风格设「生效」、补「常用词/禁用表达/正例」,重新生成——语气随之变,旧版保留可追溯。
4. **存草稿**:满意后一键存草稿。**系统只存草稿,发布永远你人工点**(小红书/抖音/快手/B站自动进草稿箱;视频号半自动:人工传视频,系统填短标题+描述后提醒你发)。
5. **标记完成/复盘**:点「标记完成」写成品审核库④;发布后点「复盘」写发布复盘库⑤,闭环。

### 5.3 单链接快速处理
```bash
od baokuan link "https://www.douyin.com/video/xxxx"
```
> 小红书**单链接**受数据源接口限制(返回推荐流),请改用**关键词采集**;其余 5 平台单链接正常。

## 第 6 章　全自动 / 定时运行

`od baokuan scheduled` 读监控配置库⑥所有启用项逐个跑完整链路。两种挂法。

### 6.1 用 macOS 定时(cron)
终端输入 `crontab -e`,加一行(每 2 小时一轮):
```bash
0 */2 * * * /path/to/od baokuan scheduled >> ~/baokuan.log 2>&1
```
`/path/to/od` 换成 `od` 真实路径(问交付方或用全路径),保存退出即生效。
**成功标志**:`~/baokuan.log` 出现运行记录,飞书选题池②/审核库④陆续有新数据。
> `scheduled/account/link` 走完整链路(含转写/AI/可能出图),单次几分钟正常,**别把间隔设太短**;只想高频看选题用 `od baokuan collect`。

### 6.2 交给 AI 智能体
让 Hermes/Claude 这类智能体按节奏调 `od baokuan scheduled` 采集、`od baokuan regenerate` 处理飞书标「重新生成」的稿,并用大白话汇报。核心业务不依赖智能体,用不用都能靠 cron 全自动跑。

## 第 7 章　封面生成

### 7.1 界面方式
创作台发布/封面环节上传参考封面、填标题即可生成并注入。

### 7.2 命令方式
```bash
# 参考封面 → 同类视觉语言新封面(抖音竖版+B站横版),中文程序叠字不错字
od baokuan cover gen --title "月薪3000的直男,相亲现场有多惨?" \
  --ref /path/参考封面.jpg --platforms douyin,bilibili --record-id <审核库record_id>
# 只改标题:不重新出图(不花图像模型钱),秒出新版
od baokuan cover rerender --bg <上一步的 *_bg.png> --title "被拒17次后,我终于悟了相亲的真相"
```
- `--record-id <审核库记录ID>` 时成品图自动传到该记录「封面成品」附件。
- 想先让系统看懂参考封面结构:先 `od baokuan cover analyze --ref <图|URL>`。
- 视觉解析精度取决于 2.4 的火山视觉模型是否开通(未开通走图生图+主色也 OK)。

## 第 8 章　运维(成本 / 失败重试 / 备份 / 自启)

界面在**账号页 →「运维」卡片**,每项都有等价命令。
- **看成本**:运维卡片「近7天成本」(LLM tokens/语音次/图像张/TikHub次) 或 `od baokuan cost --days 7`。
- **失败任务查看+重跑**(不丢任务):运维卡片「失败队列」点「重跑」,或 `od baokuan failed` / `od baokuan retry --limit 5`。失败原因也在飞书复盘库⑤「错误摘要」。
- **一键备份**:运维卡片「一键备份」或 `od baokuan backup`,产物 `.tar.gz`(含引擎数据+全部配置含Key+应用数据;可再生运行时不打进,新机自动重建)。
- **开机自启**:运维卡片开关或 `od baokuan autostart on/off/status`,注册 `~/Library/LaunchAgents/com.workbuild.autostart.plist`。

## 第 9 章　迁移到新电脑

三步,Key 和数据都在备份包里。
1. **旧电脑备份**:`od baokuan backup --out ~/爆创备份.tar.gz`,拷到新电脑。
2. **新电脑装应用**:按第1章装好首启(等引擎自动装 1–5 分钟)。
3. **新电脑恢复**:把备份包交给交付方用恢复命令还原(`python scripts/ops.py restore --from ~/爆创备份.tar.gz`)。
**成功标志**:恢复后知识库/账号/配置都在,`.env` 里 Key 也回来,飞书数据中心链接仍指向你原表。
> 飞书 10 张表本在你飞书云端,不随电脑走;新电脑连同一飞书账号就能继续用。

## 附录　od 命令速查表

> 所有命令加 `--json` 得机器可读输出。看不懂就整行复制给交付方。

### 采集/生产 —— `od baokuan`
| 命令 | 作用 | 写哪些飞书表 |
|---|---|---|
