## 二、od baokuan 命令是什么、要开 cmd 吗(你问的第 3 条)

**日常使用完全不需要命令行。** 那些 `od baokuan ...` 命令是给"自动化调度和远程维护"用的(需要维护端环境),你在界面上都有等价操作:

| 命令 | 界面等价操作 |
|---|---|
| `od baokuan collect`(关键词采集) | 创作页 →「真抓爆款」 |
| `od baokuan scheduled`(定时巡检) | 数据中心 →「监控配置库」启用关键词后,由调度器自动跑 |
| `od baokuan cost`(成本报表) | 数据中心 → 成本相关表 |
| `od baokuan failed / retry`(失败队列) | 失败的任务会进队列自动可重跑,界面报错会显示原因 |

**日志怎么看**:
- 界面优先:每次采集/AI 任务的结果和报错都直接显示在页面上(新版报错会写明白原因和该去哪处理)。
- 文件日志(给维护排查用):`C:\Users\<你的用户名>\AppData\Roaming\WorkBuild\namespaces\baochuang\logs\` 下的 `daemon\latest.log` 等。

**自检修复三板斧**(遇到不对劲先按顺序试):
1. 完全退出 App 重新打开(右下角托盘也退干净);
2. 看报错文字说的是哪家服务商 → 按上面对照表去那家查 key/余额;
3. 「设置 → 媒体生成」确认各家 key 都填了、没有多余空格。
还不行就把**报错截图 + 大概时间**发给我们,日志里能定位。

## 三、洗稿功能(你反馈的核心问题,已修复——怎么用)

你说的完全属实:旧版 AI 只拿到标题、从零瞎写。新版已把整条洗稿链路接通:

**短视频洗稿(带原视频链接的选题)**:
1. 候选选题里选一条**带原文链接**的(真抓爆款采来的都带),点「去创作」;
2. 系统自动:下载原视频 → **转写口播文案**(会提示"已转写原视频口播文案 ✓");
3. 点「AI 写脚本」——AI 现在按固定顺序做:
   **先拆出原视频的观点 → 换一套表达重写(换例子/换句式,不照抄) → 按你的提示词补 1-3 个新观点 → 衔接成完整口播**。
4. **想加自己的观点**:写在「按我说的改」/补充要求框里,例如:"补一个观点:发型比穿搭见效更快,再加一个理发店沟通话术"。

**公众号洗稿**:选题带原文链接 → 点去创作时会自动取回原文正文(提示"已取回原文 ✓") → AI 写作按同样的"拆观点→改写→补新观点→衔接"来。

注意:原视频如果本身没什么口播(纯 BGM 卡点视频),转写不出文字,AI 就只能按标题+角度写——这是素材本身的限制,换条有口播的爆款即可。

## 四、切入角度是什么(你问的第 6 条)

**切入角度 = 同一个选题,你打算从哪个视角讲**。它会直接进 AI 的提示词(新版已生效,旧版没读它——也已修复)。

举例,选题都是「男生变帅」:
- 角度 A:"从发型入手的低成本变帅" → AI 写发型攻略;
- 角度 B:"反常识——过度护肤反而毁脸" → AI 写避坑向;
- 角度 C:"月老吐槽式:择偶标准悖论" → AI 写情感共鸣向。

同题不同角度=不同的稿子。不填也行,AI 会自己定;填了就按你的来。

## 五、最低阈值 / 时间窗 / 检测频率(你问的第 8 条)

都在数据中心的表里,含义如下:

- **最低阈值**(监控配置库每行):**播放/阅读量下限**。低于这个数的内容直接不要。填 0 或不填=不设限。例:填 `10000` = 只要热度 1 万以上的。
- **时间窗**(监控配置库每行):**只看这个时间范围内发布的内容**。`7d` = 只采最近 7 天发布的;`30d` = 最近 30 天。你理解得对。
  - 小提示:公众号爆文榜的数据源(极致了)单次只支持 7 天跨度——新版会自动分段拼接,你选近半年也能出结果(旧版直接 0 条,已修复)。
- **检测频率**(在「监控配置」系统配置表,配置项=`检测频率`,值填**分钟数**):自动巡检多久跑一轮,默认 **120 分钟**。改成 `60` 就是每小时一轮。

## 六、监控规则和创作页搜索是什么关系(你问的第 9、10 条)

两个入口,分工如下:

- **创作页「真抓爆款」**(手动):按你**页面上勾的筛选**来(四个档位+时间窗)。
  - **四个档位一个都不勾 = 自动降档模式**(推荐):系统从严到松自动找,冷门词也会给你相对最好的几条,最后兜底放宽到"不限时间"——**不会再出现全不勾也 0 条**(已修复;你之前 0 条的另一半原因是 TikHub key 失效,换新 key 即可)。
  - 勾了档位 = 手动模式:严格按你勾的筛,宁缺毋滥。**提示:冷门词别勾档位**,勾了只会更严。
- **监控配置库**(自动):作用于**定时巡检**,巡检采到的爆款会写进数据中心「今日爆款选题池」,**并且(新版)自动出现在创作页的候选选题列表里**,每条可直接点「去创作」——你之前问"监控到的视频在哪操作",现在答案就是:**创作页候选列表里,直接操作**。
