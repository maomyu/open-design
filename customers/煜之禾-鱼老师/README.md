# 煜之禾 · 鱼老师

- **slug**：`yuzhihe`　别名：鱼老师 / 于老师 / 煜之禾
- **定位**：个人自媒体（个人 IP）——**短视频爆款**全链路 + 公众号文章
- **版本**：custom（未授权功能不渲染）
- **来源分支**：`video-auto-煜之禾-爆款引擎`（当前主力开发分支）
- **进度**：开发中，逐功能实测→全绿后推分支

## 原始需求

见 [`specs/current/media-studio.md`](../../specs/current/media-studio.md)。核心：帮个人自媒体做
**「真抓爆款 → 仿写口播 → 一键存草稿」**的短视频流水线，覆盖抖音/快手/视频号/B站/小红书；
数据沉淀到**飞书数据中心**；用**个人自媒体知识库**（人设/风格/金句）让 AI 写得像本人。

**关键约束**（详见 memory）：
- 短视频平台下载**一律走 TikHub**（反爬平台）；采集**真人模拟输入**（sendInputEvent），不用 JS 合成事件。
- 发布 = **自动到草稿，人工点发布**（对外动作永远人工）。
- 安装包实测：不用 chrome-devtools/扩展，用户点 UI、我改代码。
