# 中国维澳 · 翟总

- **slug**：`zhongguoweiao`　别名：翟总 / 中国维澳
- **定位**：**企业**——只做**文章**（公众号 / 微博 / 知乎），配**企业知识库**
- **版本**：custom（未授权功能不渲染——短视频/笔记/飞书等一律看不到）
- **来源分支**：`video-auto-6.1-翟总`（origin 默认分支；功能最终归并到超集，按 manifest 裁剪打包）
- **进度**：迁移中（从独立分支并回超集 + license 裁剪）

## 需求

企业主体做**公众号 / 微博 / 知乎**的图文内容营销。核心诉求：AI 按**企业口径**写文章——
公司主体、资质背书、产品服务、客户案例、品牌调性都沉淀在**企业知识库**里，写作时按类注入，
出稿贴合企业身份、可信、带背书。**只要文章，不要短视频那一套。**

## 功能清单与进度

### 文章创作台（article.*）
- [x] 公众号（article.wechat-mp）：选题→写作→封面→存草稿（微信 MP `draft/add`）
- [x] 微博（article.weibo）：写作 + 一键填发布框（微博无草稿箱，停发送前一步）
- [x] 知乎（article.zhihu）：写文章 + 一键存草稿（写作页自动保存）

### 企业知识库（kb.enterprise）★本次新建
- [x] **企业库分类**：公司主体 / 资质背书 / 产品服务 / 客户案例 / 品牌调性 / 常见问答 / 其他
- [x] 与个人库**分类隔离**（企业分类 id 带 `ent-` 前缀，数据不串）
- [x] AI 写文章时按类注入企业素材

### 横切能力
- [x] cap.ai（写作）· cap.image（配图/封面）· cap.handoff（一键存草稿）· cap.publish（发布）

## 不包含（关键）

- **短视频全平台**（sv.*）、**小红书图文**（note.xiaohongshu）——翟总不做短视频/笔记
- **飞书数据中心**（integrations）——企业文章场景暂不需要
- **配音/成片**（cap.tts / cap.video）——文章不需要
- **个人自媒体知识库**（kb.personal）——翟总用企业库，不用个人 IP 那套人设/口播风格

> 说明：原「翟总分支」并**没有**独立的企业知识库，知识库分类和鱼老师完全一样（个人自媒体那套）。
> 本次（2026-07-16）才**真正新建**了企业知识库并按 license 拆分——翟总此后看到的是企业库。
